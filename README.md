# QTL-seq-Pipeline
This repository contains an end-to-end QTL-seq analysis pipeline for identifying genomic regions associated with phenotypic traits using bulked segregant analysis (BSA) and next-generation sequencing (NGS) data.
The pipeline processes raw FASTQ files from High Bulk and Low Bulk samples, aligns reads to a reference genome, calls variants, and calculates SNP-index and ΔSNP-index to detect candidate QTL regions.
